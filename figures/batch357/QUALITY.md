# Batch357：GitHub 深度学习工具对比

来源为 Chen 与 Guo 的 Mathematics 2023 论文（DOI 10.3390/math11081777），图 8，CC BY 4.0。
原图、下载链接和哈希见 `source/`。

重绘保留 12 个工具、三类指标及 0–200,000 的纵轴。每组根据原图三种填充颜色在柱中心取样，
以第 1167 行为零线、第 322 行为 200,000 刻度，将柱顶的像素位置转换为柱高。
共辨识出 30 根柱。其余六个位置看不到对应颜色，源码以 `none` 表示。
柱高为原图读数的近似值，不能作为精确计数或当前 GitHub 数据。

对照最终预览，核对分组顺序、颜色、图例和斜排标签。未发现标签压住网格线、外框或相邻标签。
单图校验和文字碰线校验均通过。结果见 `validation.json` 与 `text-clearance-validation.json`。
